# 字体系统

## 字体组合

- 中文主标题：阿里妈妈数黑 Bold；缺失时回退到阿里巴巴普惠体 Heavy 或 ExtraBold。主标题保持厚重、方正和清晰。
- 中文正文：阿里巴巴普惠体 SemiBold；缺失时回退到 Medium 或系统黑体中粗。
- 优设标题黑仅用于需要速度感的短句变体，不作为默认标题字体。
- 英文背景字：Barlow Condensed ExtraBold；用于超大裁切字和结构性字景。
- 英文元数据：Rajdhani SemiBold；用于编号、Key、Diffuse 和流程代码。
- L10 衬线背景字：Lora；缺失时回退到 Georgia。

## 字号层级

以 1080 × 1350 px 为基准：

| 层级 | 建议字号 | 用途 |
|---|---:|---|
| 超大背景字 | 220–310 px | 裁切字景与版式骨架 |
| 主标题 | 88–136 px | 每张卡的核心信息 |
| 流程节点 | 42–54 px | L09 关键词与步骤 |
| 正文 | 40–50 px | 一至两行辅助说明 |
| 眉题 | 34–42 px | 编号与栏目 |
| 技术标签 | 25–31 px | Key、Diffuse、流程代码 |

标题与正文至少相差 1.8 倍。眉题和技术标签使用不同字体与字距，避免所有文字落在同一视觉音量上。
