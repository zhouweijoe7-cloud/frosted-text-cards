# 版式规则

## 自动选版优先级

1. 明确对比、转折或前后差异：L04 双层叠片。
2. 三个以上步骤、动作或并列关键词：L09 纹理切片。
3. 产品、工具、功能或分类介绍：L07 文件夹穿插。
4. 单一专业概念或术语解释：L08 背光标本。
5. 封面、情绪表达或收尾结论：L10 凝露叠字。
6. 极短金句、问题或强结论：L03 横向磨砂带。
7. 其余知识点与方法总结：L01 裁切字景。

## 容量边界

| 版式 | 主要用途 | 标题 | 辅助文字 |
|---|---|---|---|
| L01 裁切字景 | 通用知识点、方法总结 | 4–8 字 | 1–2 行 |
| L03 横向磨砂带 | 金句、问题、短结论 | 4–10 字 | 1 行 |
| L04 双层叠片 | 对比、转折、两种状态 | 两组短语 | 1 行 |
| L07 文件夹穿插 | 工具、功能、分类 | 4–8 字 | 1 行 |
| L08 背光标本 | 概念、术语 | 2–6 字 | 1 行 |
| L09 纹理切片 | 流程、关键词组 | 2–4 个节点 | 极少 |
| L10 凝露叠字 | 封面、情绪、结论 | 2–4 字 | 极少 |

同一系列允许重复使用 L01。其余强调型版式通常各使用一次，避免视觉节奏过度跳跃。
